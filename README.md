# Тихий мир / QuietWorld

Автономная фэнтезийная симуляция для Windows x64.

## Подключение

После первой успешной сборки в Actions укажите в игре V5.7.0 в меню «Источник обновлений»:

`https://raw.githubusercontent.com/dubenkodanil-png/QuietWorld/main/updates/latest.json`

Публикация выполняется только после сборки и тестов. Не загружайте в репозиторий сохранения, пароли или личные файлы.

## Выпуск версий

Обновить исходный код, номер версии в `game/update.go`, отображаемые версии и список изменений; последним коммитом изменить `release.json`. GitHub Actions соберёт пакет для встроенного обновления и установщик, затем опубликует их с контрольной суммой SHA-256.

Контрольная сумма защищает от случайной порчи, но не заменяет цифровую подпись. Установщик и перезапуск необходимо проверить на Windows.
